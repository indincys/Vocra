# Vocra 0.4.0

## 修复：App 会自己退出

关闭主窗口会连同菜单栏图标和全局快捷键一起把整个 App 结束掉——看起来就像它「时不时自己退出」。现在关闭窗口只会收起窗口，Vocra 继续留在菜单栏待命，划词快捷键照常可用。

## 解析页面重做

- **不再弹浮动小窗**：按 `⌥Space` 后，解析结果显示在主窗口新增的「查词」区域。
- **只保留三样东西**：整句译文、句子拆解、重点单词。原来的句子关系图、句意解析、抓主干已移除。
- **就地讲解**：句中每个成分带颜色下划线，重点单词额外高亮。点任意一个，讲解直接在这个词所在行的正下方展开，眼睛不用离开原句。
- **更快**：输出字段从六组减到三组，并且不再需要第二次请求（原先关系图和重点词要再发一轮）。现在一次请求出全部内容，译文最先生成，所以最快能读到的东西来得更早。

## API Key 改为本地加密保存

API Key 不再存进系统钥匙串，改为保存在 Vocra 数据目录下的本地加密文件（`secrets.enc`，仅本人可读）。

原因：Vocra 没有 Apple 开发者证书，钥匙串按应用授权的「始终允许」无法在重新签名后存活，导致每次更新 App 都会重新弹授权框。

升级时会自动把已有的 Key 从钥匙串迁移过来，无需手动操作。请注意：**如果之后回退到 0.3.0 或更早版本，需要重新填写一次 API Key**。

加密只用于避免密钥以明文出现在备份、截图和全盘搜索里；主密钥与密文存放在同一目录，不构成独立的安全边界。
