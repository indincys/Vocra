# Vocra 0.3.0

## 新增：阅读区（长文收录）

- 在任意 App 中选中一整段或一篇文章，按 `⌥⇧Space`（可在设置中改）即可收录进 Vocra，不再弹出划词面板。
- 新增「阅读」区域：文章保持原有分段，逐句按语法着色。点击任意一句，句子结构、语法讲解和重点词汇会直接在这一句下方展开，不跳到别的面板。
- 收录后立即在后台逐句解析，解析结果随句子一起存进本地数据库，再次打开秒开、不再消耗额度。
- 收录的文章默认在最后一次打开的 30 天后自动清除，可在设置中改为 7 / 30 / 90 天或永久保留，缓存的解析结果一并清理。

## 新增：开机自动启动

- 设置中可开启「开机自动启动」，登录后只在菜单栏后台运行：没有 Dock 图标，也不会抢走当前窗口的焦点。第一次打开主窗口时才恢复成普通应用。

## 其他

- 全局快捷键改为多组管理，划词与收录各占一组，录制时会拒绝与另一组重复的组合键。
- 菜单栏新增「收录选中段落」。
